A fork of [IvanMathy/Boop](https://github.com/IvanMathy/Boop) with native tabs, themes, font settings and fewer bundled libraries. There are no prebuilt releases of this fork; build it from source. The original Boop is still available from its own repository and the Mac App Store.

### How to build from source

- Clone or download a copy of the repository
- Open `Boop/Boop.xcodeproj`
- Press play
